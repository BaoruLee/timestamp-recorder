## 📖 使用教程

> 📱 **不用特地翻到这个网页**：App 内右上角「⋮」菜单 →「使用教程」，或「设置」页 →「查看图文教程」，都能直接跳到这一节。

### 界面速览

打开 App 一共四个页面，后面所有操作都围绕它们：

| 页面 | 怎么进去 | 里面有什么 |
|:---|:---|:---|
| **主页** | 点桌面图标 | 事件卡片列表、右下角圆形「＋」按钮、右上角「⋮」菜单 |
| **事件详情** | 点主页任意一张卡片的**中间区域** | 大记录按钮、「撤销上一条」、该事件的全部记录 |
| **统计** | 主页或详情页右上角菜单 → 统计 | 概览数字、各事件柱状图、近 14 天趋势 |
| **设置** | 主页右上角菜单 → 设置 | 快捷按钮位置、排序方式、小组件、备份、关于 |

### 1️⃣ 新建第一个事件

1. 在主页点**右下角那个圆形「＋」按钮**（60dp 的液态玻璃圆钮）。
   - 它在屏幕底部靠右，默认离右边和底边各 24dp；也可以在设置里把它换成底部**左侧**或**居中**（见第 7 节）。
2. 弹出「添加事件」对话框，填两样东西：
   - **名称**：想记什么就写什么，例如「喝水」「背单词」「吃药」。留空点保存会红字提示「请输入事件名称」，存不进去。
   - **颜色**：对话框里是一排 6 列共 12 色的小圆点，默认已经随机帮你选中一个。这个颜色会用在**卡片圆点**、**快捷按钮**、**统计柱状图**和**桌面小组件**上，挑个一眼能认出来的。
3. 点「保存」，卡片立刻出现在列表里。

### 2️⃣ 记录一条时间戳

同一个事件有三个记录入口，按场合挑：

| 入口 | 手指点哪里 | 点完发生什么 |
|:---|:---|:---|
| **主页快捷按钮**（最快） | 事件卡片**最右侧**那个彩色胶囊按钮（里面是「＋」和当前条数） | 立刻写入一条，按钮上的数字 +1，底部弹出「已记录 事件名」 |
| **详情页大按钮** | 点卡片中间进入详情页 → 点最上面那块**填满事件色的大按钮「记录此刻」** | 写入一条，列表顶部立刻出现新记录，底部弹出「已记录 2026-09-14 09:41:53」 |
| **桌面小组件** | 在桌面上点组件本体 | 同上，**不用打开 App**（见第 6 节） |

三个入口写进去的都是**毫秒精度的当前时间**，效果完全一样。

### 3️⃣ 拖动排序：手指一定要按在那个「≡」手柄上

这一步最容易按错地方，请看清：

**先决条件**：设置 → 事件排序 → 选「**手动排序**」（默认就是它）。
如果选了「按最近记录」，卡片左侧的拖拽手柄会**直接消失**，这时拖不动——想拖先切回「手动排序」。

**手指按哪里**：

- 每张事件卡片的**最左边**有一个灰色「≡」手柄（两条横线的图标，约 32×36dp 一块区域，在彩色圆点的左边）。
- **必须把手指按在这个「≡」手柄上**。
- 按住**的瞬间**就能拖，**不需要长按等待**，也没有震动反馈。
- 按在卡片其它位置（事件名、颜色圆点、空白处）都**不会**触发拖动——那些地方是「打开详情页」的点击区。

**动作**：

1. 手指按住「≡」不放。
2. 卡片会**浮起来**（下方多一层阴影），跟着手指上下移动。
3. 其他卡片自动让位，过程中实时换位。
4. 拖到目标位置，**松手** → 顺序立即写入本地，杀掉 App 重开还是这个顺序。

**小技巧**：

- 一次只能拖一张。
- 列表很长时，把卡片拖到屏幕**上边缘或下边缘**停一下，列表会自动滚动，方便跨屏搬运。
- 手动顺序只存在本机、也没有「撤销排序」按钮：拖乱了只能自己再拖回去。所以大改动之前，建议先在设置里导一份备份。

### 4️⃣ 一张卡片上有四个可点区域，别按错

从左到右：

| 位置 | 长什么样 | 点了会怎样 |
|:---|:---|:---|
| 最左 | 灰色「≡」手柄 | **按住可拖动排序**（仅手动排序模式下显示） |
| 中间 | 彩色圆点 + 事件名 + 下方「共 N 条记录 / 最近时间」 | 打开该事件的**详情页** |
| 右偏 | 竖排三点「⋮」 | 弹出菜单：**编辑事件** / **删除事件** |
| 最右 | 彩色胶囊按钮（「＋」+ 条数） | **直接记一条** |

⚠️ 「删除事件」会把它名下的**所有记录一起删掉**，会先弹确认框。删之前建议先去设置里导一份备份。

### 5️⃣ 详情页：管理记录

**记一条**：点顶部**「记录此刻」**大按钮（颜色就是该事件的颜色）。
**撤销手滑**：点它下方的**「撤销上一条」**，删掉最新那一条；没有记录时会提示「没有可撤销的记录」。
**看记录**：列表里**最新的在最上面**，每行左边是编号（`#12`、`#11`… 递减），右边是完整时间 `2026-09-14 09:41:53` 和 `Unix 秒：1757...`。

**单条操作**（普通模式下）：

| 操作 | 手势 |
|:---|:---|
| **复制这条时间** | **点一下这一行**任意位置，或点行右侧的「复制」按钮。复制到剪贴板的内容是 `2026-09-14 09:41:53  (Unix 秒: 1757...)`，粘到微信、备忘录都行 |
| **删除这条** | **长按这一行** → 弹出确认框 → 点「删除」 |

**批量删除**：

1. 点标题栏右侧的**复选框图标**（即「批量管理」）。
2. 底部升起一条操作栏：`全选` ｜ `已选 N 项` ｜ `删除(N)` ｜ `取消`。
3. 此时**点每一行**或**长按每一行**都是在打勾 / 取消勾，行前出现复选框，行右的「复制」按钮暂时隐藏。
4. 点「全选」一下勾满，按钮会变成「取消全选」。
5. 点「删除(N)」→ 二次确认「将删除选中的 N 条记录，无法恢复」→ 确认后一次性删完。
6. 点「取消」退出批量模式。

**右上角「⋮」菜单**还有：编辑事件 / 导出记录 / 清空记录 / 删除事件 / 统计。
其中「导出记录」会把该事件的全部记录导成 CSV（UTF-8 带 BOM，Excel 双击不乱码），三列：事件名、记录时间、Unix 秒。

### 6️⃣ 桌面小组件

**怎么添加**（HyperOS 4 实测路径）：**长按桌面空白处** → 点「**小部件**」→ 点「**全部应用**」→ **下拉到底部、点开「安卓小部件」**（原生列表）→ 找到「**时间戳记录**」，按住想要的组件**拖到桌面**，松手。

一共有三种：

| 类型 | 说明 |
|:---|:---|
| **时间戳 · 全部事件** | 列出所有事件，点哪个记哪个（最多 6 行）；一个事件都没有时，点提示语会打开 App |
| **时间戳 · 单事件** | 添加时先让你绑定一个事件，**尺寸可从 1×1 拉伸到 4×4**，版式随格子自动变形 |
| **时间戳 · 胶囊** | 2×1 横向胶囊，绑定一个事件，占位小、适合放一排 |

**绑定类组件（单事件 / 胶囊）的添加流程**：拖到桌面松手后会直接弹出「绑定事件」页 → 在列表里点一下要绑定的事件 → 自动回到桌面，组件显示出来。
不想去系统列表里翻的话，也可以从 App 内添加：设置 → 桌面小组件 → 点「全部事件 / 单事件 / 胶囊」三个按钮之一（支持该接口的桌面会弹确认框，小米等部分 ROM 会改为弹出「请手动添加」的指引）。

> ⚠️ **小米 HyperOS 4 上「一键添加」会失效**
>
> App 内那三个按钮走的是 Android 官方的 `requestPinAppWidget`（一键把组件钉到桌面）。
> 这是**桌面（启动器）自己的开关**，得由小米桌面来实现 —— **HyperOS 4 上该接口直接返回失败**，
> 所以在本机实测（小米 15S Pro / HyperOS 4）点按钮不会出现钉桌面的确认框，只会弹出「请手动长按桌面添加」的指引。
> 这不是本 App 的 bug，也不是权限或设置问题，在别的支持该接口的 ROM（原生 Android、部分第三方桌面）上是正常的。
>
> **HyperOS 4 上的正确添加方式**（也就是上面那套手动流程）：
>
> 1. 回到桌面，**长按空白处**
> 2. 在弹出的面板里点「**小部件**」
> 3. 点「**全部应用**」
> 4. **下拉到底部，点开「安卓小部件」**（原生安卓小部件列表）
> 5. 找到「**时间戳记录**」，**按住**想要的组件（全部事件 / 单事件 / 胶囊）**拖到桌面**，松手；单事件与胶囊拖上去后会弹出「绑定事件」页，点一下要绑定的事件即可

**单事件组件拉到不同尺寸，长这样**：

| 拉到多大 | 形态 |
|:---|:---|
| **1×1** | 一块事件色小方块，中间是事件名，点一下记一次 |
| **2×1 / 3×1 / 4×1**（宽、扁） | 变成横条：左边事件名，右边最近一次时间与「＋」 |
| **2×2 ~ 4×4**（方、大） | 卡片：事件名 + 最近一次完整时间（`2026-09-14 09:41:53`）；格子够大时再补出「共 N 次」与「点击记录」 |
| **1×2 / 1×4**（窄、高） | 竖向卡片，内容同上；太长的文字会自动省略，不会溢出 |

**怎么拉伸**：**长按组件**，四周出现可拖的小圆点 / 边框 → **拖住角或边**往外拉是放大、往里收是缩小 → 松手生效。
拖到哪一档就即时换成对应版式，**不用删掉重新添加**；文字大小也跟着格子缩放，1×1 不溢出、4×4 不空旷。

**重新绑定事件**：长按组件 → 在弹出菜单里选「重新配置 / 编辑」（部分桌面收在「编辑」这一项里）→ 会重新跳出绑定页，换个事件绑。

**圆角**：三种组件的圆角统一在设置里调（小 8 / 中 16 / 大 24 / 超大 32dp），改完桌面立刻刷新。
单事件组件缩到 1×1 时，圆角会自动压到 16dp 以内，免得小方块被啃成一个圆点。

**点击会怎样**：全部事件组件点某一行 → 记录**那个事件**；单事件 / 胶囊组件点整块 → 记录**所绑定的事件**。记完所有组件会一起刷新。

**组件显示「已删除」**：说明它绑定的事件被删掉了。长按组件重新配置，或者删掉组件重新添加。

### 7️⃣ 设置

主页右上角「⋮」→ 设置。从上到下六组：

| 分组 | 选项 | 说明 |
|:---|:---|:---|
| **快捷按钮位置** | 左侧 / 居中 / 右侧 | 换主页那个「＋」圆钮停的位置。选完立刻生效，退回去就能看到它换地方了 |
| **事件排序** | 手动排序 / 按最近记录 | 「手动排序」才会显示卡片左侧的「≡」拖拽手柄；「按最近记录」按最近一次记录时间降序排，没记录过的排最后 |
| **桌面小组件** | 圆角四档 | 小 8 / 中 16 / 大 24 / 超大 32dp。改完桌面所有组件立即重绘，并弹出「圆角已生效，桌面小组件已刷新」 |
| | 全部事件 / 单事件 / 胶囊 | 三个「一键添加到桌面」按钮，省得去系统小组件列表里翻（支持与否取决于你的桌面） |
| **数据备份** | 导出备份 / 从备份恢复 | 走系统文件选择器，**不需要存储权限**。导出是 JSON，包含全部事件与记录 |
| **使用教程** | 查看图文教程 | 一键用浏览器打开本文件的「使用教程」章节。主页「⋮」菜单里也有同一入口 |
| **关于与开源** | 关于与开源 | 版本号、GitHub 源码、MiSans 字体出处与许可 |

**关于备份的几点**：

- **导出备份**：选一个位置存 JSON。换机、重装、准备大改动之前建议先导一份。
- **从备份恢复**：选一个之前导出的 JSON → 弹确认框，会明确告诉你**将被覆盖的数据量**（共 N 个事件、M 条记录）→ 点「覆盖恢复」才会执行。这是**覆盖**不是合并，且不可撤销。
- 恢复完成后，桌面小组件也会一起刷新。

### 8️⃣ 统计

主页右上角「⋮」→ 统计（或者进某个事件的详情页，右上角菜单 → 统计）。

- **概览**：事件数、记录总数、记录最多的事件。
- **各事件记录数**：柱状图，每个事件一根柱子，颜色就是事件自己的颜色。
- **近 14 天记录趋势**：横轴是最近 14 天，看你这段时间记了多少。
- 从某个事件进来的话，页面顶部会显示「**当前：事件名**」，旁边有「**全部事件**」按钮可以切回全局视图。
- 一条记录都没有时，页面会提示「还没有任何记录，去主页点几下『记录』吧」。

## 🔒 隐私

不申请任何权限 —— 没有 INTERNET，没有存储、定位权限。

数据 100% 保存在应用私有存储（SharedPreferences），不上传、不联网、无后台唤醒。

「关于」页里的 GitHub 按钮是交给**系统浏览器**打开的，App 自身依旧不联网。

| **已知失效** | 小米 HyperOS 4 的「一键添加到桌面」不生效，需手动添加（长按桌面 → 小部件 → 全部应用 → 下拉到底点「安卓小部件」→ 找到时间戳记录）—— 这是桌面没实现官方接口，与本 App 无关，详见上面第 6 节 |

代码里对低版本做了降级（比如模糊效果在 Android 12 以下自动退回纯色背景），但**这些降级路径没有实机验证过**。如果在你的设备上出现异常，欢迎到 [Issues](https://github.com/baoru0908/timestamp-recorder/issues) 反馈，附上机型 + 系统版本 + 复现步骤即可。
