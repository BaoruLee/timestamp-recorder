## 📖 使用教程

### 1️⃣ 新建事件

打开 App → 点底部的「＋」→ 填名称、挑一个颜色 → 保存。

### 2️⃣ 记录时间戳

两种方式，看场合选：

- **最快**：在首页，直接点事件卡片右侧的彩色按钮（按钮上的数字是当前条数），点一下记一条，数字立刻 +1
- **看详情**：点卡片进入详情页 → 点大按钮记录，页面上会显示完整的日期时间与 Unix 秒

### 3️⃣ 整理事件顺序

- **手动**：按住卡片左侧的「≡」手柄上下拖动，松手即保存
- **自动**：在设置里切成「按最近记录」，列表就按最近一次记录的时间排列

### 4️⃣ 管理记录

在详情页里：

- **点一下某条记录** → 复制（含 Unix 秒）
- **长按某条记录** → 删除
- **右上角「批量」** → 勾选多条一次性删除
- **右上角菜单** → 撤销上一条 / 清空全部 / 导出 CSV / 查看该事件统计

### 5️⃣ 桌面小组件

长按桌面空白处 → 小组件 → 找到「时间戳记录」，有三种：

| 类型 | 说明 |
|:---|:---|
| **时间戳 · 全部事件** | 列出所有事件，点哪个记哪个（最多 6 行）；一个事件都没有时，点提示语会打开 App |
| **时间戳 · 单事件** | 添加时先绑定一个事件，桌面显示该事件颜色的大按钮与最近一次时间 |
| **时间戳 · 胶囊** | 2×1 横向胶囊，绑定一个事件，占位小、适合放一排 |

三种都可以长按拖动改尺寸；绑定类小组件长按还能重新绑定事件。
圆角可以在设置里调（8 / 16 / 24 / 32dp）。

### 6️⃣ 设置

主页右上角菜单 → 设置：

- **快捷按钮位置**：「＋」按钮放底部左侧 / 居中 / 右侧
- **事件排序**：手动拖拽 / 按最近记录
- **小组件圆角**：四档切换，即时刷新桌面
- **一键添加到桌面**：不用去系统小组件列表里翻，在 App 里点一下即可申请添加
- **数据备份**：导出 / 从备份恢复（JSON）
- **关于与开源**：版本信息、源码仓库、字体出处与许可

## 📥 安装与升级

在 [**Releases**](../../releases) 页面下载最新的 `TimestampRecorder_vX.Y.Z.apk`，直接安装即可。

- 所有版本的安装包都使用**同一把签名证书**，因此可以**直接覆盖安装**完成升级——**已有事件与记录数据不会丢失，也不需要先卸载**。
- 首次安装若被系统拦截，按提示允许「安装未知来源应用」即可。
- 换机或重装前，建议先用「设置 → 数据备份」导出一份 JSON，装好后从备份恢复。

## 🔨 构建

```powershell
.\gradlew.bat assembleRelease
```

需要 **JDK 17** 与 **Android SDK 34**（用 JDK 25 会导致 AGP 构建失败）。

一键构建 + 签名 + 发布：`.\tools\release.ps1`（会校验证书指纹，确保产出可直接覆盖安装的包）。
