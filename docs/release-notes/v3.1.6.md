# 时间戳记录 v3.1.6

三处观感修正，都是上一版做完后实测发现的问题。

## 🐛 修复

- **顶部玻璃栏现在真的罩住状态栏了**。上一版这扇窗口被系统摆到了「应用可用区」里（从状态栏下沿
  才开始），状态栏那一块没有被玻璃覆盖。原因是只给 `FLAG_LAYOUT_IN_SCREEN` 不够，必须再给
  `FLAG_LAYOUT_NO_LIMITS`（前提是窗口**显式指定了宽高且是 floating**，否则会退化成整屏窗口）。
  现在窗口从屏幕 y=0 开始，栏高与列表留白仍按窗口真实位置反推，不会多算一个状态栏。
- **时间线拉到底不再有一截没上色**。以前列表底部固定留白 140dp，那段是空心的，滚到最后一屏时
  收笔之后会露出一截没颜色的底轨；现在取消这段留白，改由「收笔」那一段自己盖住底部。
- **染色过渡改回最简单的两色线性渐变**（本色 ← 上一条的颜色），去掉了之前的多点插值 ——
  它在大色差（如红→绿）时会经过奇怪的中间色，看起来像「断点」。现在就是匀匀的一段过渡，
  相邻两行首尾同色，整条线依旧连续。

## 📥 安装与升级

- 附件 `TimestampRecorder_v3.1.6.apk`，使用与历史版本**同一把证书**签名，
  因此可以**直接覆盖安装** —— **已有事件与记录数据不会丢失，也不需要先卸载**。
- 从任意旧版本升级只需装上这个包即可，其他都不用动。
