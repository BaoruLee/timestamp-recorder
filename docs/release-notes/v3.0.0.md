# 时间戳记录 v3.0.0

一次彻底的界面与体验重构。核心没变 —— **点一下就记下此刻**，但整个 App 从里到外重新做了一遍。

## 🎨 全新界面

- **Material 3 动态取色**：跟随你的系统壁纸生成配色，深色模式自动跟随
- **玻璃质感卡片**：主界面、设置页、关于页统一为液态玻璃风格，设置页每个功能组各自成卡片、组间自然分隔
- **沉浸式状态栏 / 导航栏**：背景渐变延伸到状态栏，没有黑边
- **内置小米 MiSans**：为控制体积只嵌入了常用字子集，字体未作任何修改，出处已在「关于」页注明

## 🧩 桌面小组件

三种类型，都在桌面直接记，不用打开 App：

| 类型 | 说明 |
|:---|:---|
| **时间戳 · 全部事件** | 列出所有事件，点哪行记哪个 |
| **时间戳 · 单事件** | 绑定一个事件，**尺寸可从 1×1 自由拉伸到 4×4** |
| **时间戳 · 胶囊** | 2×1 横向胶囊，占位小，适合排一排 |

**单事件组件这一版可以自由变形了**：拖到哪一档就即时换成对应版式 —— 1×1 是色块、扁格是横条、
方格是卡片、窄高格是竖卡，文字大小跟着格子缩放，1×1 不溢出、4×4 不空旷，**不用删掉重新添加**。

## ↕️ 拖动排序

主页卡片左侧新增「≡」拖拽手柄（仅在「手动排序」模式下显示），按住它上下拖动即可调整顺序，松手即保存。
不想手动排的话，可以在设置里切成「按最近记录」，让列表按最近一次记录时间自动排列。

## 📊 统计页

- 概览：事件数、记录总数、记录最多的事件
- 各事件记录柱状图，每根柱子的颜色就是事件自己的颜色
- 近 14 天记录趋势

## 💾 数据备份

导出 / 从备份恢复，全量 JSON。走系统文件选择器，**不需要存储权限**。
恢复前会明确告知将被覆盖的数据量，且是「覆盖」不是合并 —— 换机或重装前建议先导一份。

## 🖼 全新自适应图标

换成 Adaptive Icon（前景 + 背景两层）：背景为深蓝 `#14306B`，前景单独一层并缩进安全区内，
各家桌面的圆形 / 方形 / 水滴遮罩都不会把主体切掉。

## 📖 App 内教程入口

主页右上角「⋮」菜单，以及设置页，都能直接打开图文教程。教程按操作细节逐条写清
（比如拖动排序到底该按哪块区域），不用一边读一边猜。

## ⚠️ 已知限制

- **目前只在一台设备上完整实测过：小米 15S Pro（HyperOS 4）**。其他品牌与 ROM、平板与折叠屏、
  Android 12 以下的老机型均未验证。代码里对低版本做了降级处理，但降级路径没有实机验证过。
- **小米 HyperOS 4 上「一键添加到桌面」不生效**。App 内那三个按钮走的是 Android 官方接口
  `requestPinAppWidget`，需要桌面（启动器）自己实现，HyperOS 4 会直接返回失败 —— 点了不会弹确认框，
  只会出现手动添加指引。这不是 App 出错，在原生 Android 等桌面正常的系统上可以一键钉住。

  HyperOS 4 手动添加：长按桌面空白处 → 选「添加工具」→ 顶部切到「小部件」→
  往下翻到「时间戳记录」→ 按住想要的组件拖到桌面即可。

## 📥 安装与升级

- 附件 `TimestampRecorder_v3.0.0.apk`，使用与历史版本**同一把证书**签名，
  因此可以**直接覆盖安装** —— **已有事件与记录数据不会丢失，也不需要先卸载**。
- 首次安装若被系统拦截，按提示允许「安装未知来源应用」即可。
- 换机或重装前，建议先用「设置 → 数据备份」导出一份 JSON，装好后从备份恢复。

> 关键操作有疑问，先看 App 内「⋮」→「使用教程」；也可以直接到 [Issues](../../issues) 反馈，
> 附上机型与系统版本即可。
