## 改进

- **「⋮」和弹出的菜单不再隔着一截**：原来 ⋮ 只居中标题那一行，下面还挂着一行副标题，
  菜单挂在玻璃栏下沿就离按钮近 40dp。现在把标题与副标题竖着排成一组，
  ⋮ 改为**垂直居中于整块栏** —— 它的下沿离栏底只剩几 dp，菜单直接贴在按钮下沿 6dp 处展开，
  既紧凑、也不会压到左边那行副标题。顺带整块栏也变薄了一点，更利落。

- **底部 Tab 的图标与文字收紧**：图标 24dp → 20dp，图标与文字的间距 8dp → 6dp，
  「事件 / 时间线」这一组看起来更紧凑、更像一个整体。

- 依旧是**零权限、不联网、无广告**，数据只在本机。
