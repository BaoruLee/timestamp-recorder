# TimestampRecorder v4.0.0

## 🎉 全新玻璃架构：全 App 统一的「液态玻璃」

这是 v1.0 以来最大的一次视觉架构重构。顶部额头、底部胶囊岛、tab 中间的加号圆钮、
全部二级页面顶栏，统一为**实时液态玻璃**——物理折射 + 色散 + GPU 高斯，
列表滚动时内容从玻璃底下穿过、被实时折射，跟手无延迟。

## ✨ 主要变化

- **液态玻璃统一全 App**：首页额头 / 底部胶囊岛 / 二级页面顶栏同材质、同语言
  （源自 MIT 协议的 [AndroidLiquidGlassView](https://github.com/QmDeve/AndroidLiquidGlassView)，源码集成并本地化）。
- **加号新家**：从悬浮角落移入 tab 栏正中间，做成与岛**同材质的液态玻璃圆钮**，点按即记录。
- **页面切换回归桌面式平移**：相邻页元素 1:1 实时露出（修复相邻页延迟渲染的问题）。
- **滑块圆角与岛统一**（完整胶囊），且与中间圆钮互不遮挡。
- **状态栏黑化在全 App、全部深浅色模式下保持**。

## 🧹 架构清理（大版本理由）

- **删除「独立窗口 + 系统级模糊」浮窗架构**：约 300 行。三重实验（PANEL 子窗口 / 仅岛窗口 /
  focusable 自亮）证明**任何浮窗都会夺走状态栏 appearance 且无法点亮**，与系统级模糊物理互斥——
  这条路已封闭，代码一并移除防止回归。
- **移除 BlurView 依赖**、`SystemBlur`、`bg_top_bar` / `bg_bottom_nav` / `fab_liquid` 等过时资源、
  `view_top_bar` / `view_bottom_nav` 窗口布局、以及「加号位置」设置项。
- 保留：全部核心功能（记录 / 拖拽排序 / 时间线 / 统计 / 三种小组件 / 备份恢复 / CSV 导出）。

## 📱 兼容性

- 液态玻璃完整效果需 **Android 13+**（AGSL 着色器）；更低版本自动退回普通玻璃形态，功能无损。
- 状态栏黑化在所有支持机型上不再受玻璃形态影响（零浮窗架构）。
