# 时间戳记录 v3.1.5

时间线的观感调整 + 顶部工具栏重做。

## ✨ 改进

- **时间线的颜色过渡更自然**：相邻记录之间不再整行慢慢晕染，而是收进一条**约 22dp 的过渡带**里
  完成换色；过渡走 **HSV 最短色相路径**（红→绿走黄、蓝→红走紫，不会经过脏灰），并按缓入缓出
  分 5 段插值，接缝处看得很顺。
- **时间线两头也有颜色了**：列表最上方 / 最下方各补一段「起笔 / 收笔」——起笔顶端就带颜色向下渐实，
  收笔向下渐隐但不归零。以前首条记录之前、末条记录之后只剩一条淡底轨，现在是彩色的。
- **顶部工具栏重做成「模糊的半透材质」**：这一栏被搬进独立窗口，模糊交给系统合成器（和底部胶囊岛
  同一套机制），列表滚动时内容会从玻璃栏底下穿过。右上角「⋮」（设置 / 统计 / 教程）随之一并搬进
  这扇窗口，点开是弹出菜单，动作与原菜单一致。

## 🐛 修复

- **顶部玻璃栏的高度不再多出状态栏那一段**：系统默认会把这扇窗口按状态栏再内缩一次，导致栏高多算
  一个状态栏高度、标题位置偏低。现在改为按窗口的**真实屏幕位置**反推内边距，无论 ROM 怎么摆都精确。
- 时间线列表不再预留顶部空白：竖线可以从屏幕顶端（玻璃栏之后）开始，视觉上真正贯穿上下。

## 📥 安装与升级

- 附件 `TimestampRecorder_v3.1.5.apk`，使用与历史版本**同一把证书**签名，
  因此可以**直接覆盖安装** —— **已有事件与记录数据不会丢失，也不需要先卸载**。
- 从任意旧版本升级只需装上这个包即可，其他都不用动。
