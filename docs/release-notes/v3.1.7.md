## 修复

- **第一个事件不再被顶部玻璃栏盖住**：之前列表顶部的留白算少了整整一条状态栏的高度，
  第一条卡片正好压在「额头」底下。现在按玻璃栏**下沿的真实屏幕位置**留白，
  并在窗口每次布局后重新对一次（窗口刚弹出时还没测量，量到的高度是偏小的），
  另外加了一层「状态栏 + 一栏工具栏」的底线兜底，怎么都不会再压到内容。

- **右上角「⋮」菜单不会再跑到屏幕外**：系统自带的弹出菜单是按「锚点所在窗口」定位的，
  而我们的锚点在一扇贴着屏幕顶端的独立窗口里，结果整个菜单被甩出画面。

## 改进

- **「⋮」菜单换成玻璃卡片**：跟顶部工具栏、底部胶囊岛同一套材质（系统级实时模糊，
  不是截图假模糊，滚动不掉帧）。带图标、从按钮那一角缩放淡入、点空白处收起，
  展开时「⋮」会点亮成主题色。位置固定在屏幕内，并且改成从**玻璃栏下沿**往下展开 ——
  之前从按钮正下方展开会挡住下面那行副标题。

- **底部 Tab 加了图标**：「事件」是带圆点的列表，「时间线」是一条竖线串三个节点，
  选中时图标跟着文字一起提亮。

- **README 重写**：开头先看「30 秒上手 → 它解决什么 → 和别的 App 有什么不一样 → 核心能力」，
  把真正人无我有的差异顶到最前面（0 权限、一次点击、无账号无云、无广告订阅、
  小组件 1×1~4×4 自适应、同一签名覆盖升级不丢数据）。
  冗长的细节折叠进「展开」里，教程保留保姆级但压缩成表格 + 步骤。
