## 改进

- **权限引导按钮全机型可见**：上一版只在小米 / 红米上显示的「权限 / 应用设置」引导按钮，
  现在所有机型都会显示 —— 因为各厂商对「一键添加到桌面」的限制不同（小米要权限、
  OPPO 逐步收紧、vivo 需上架组件平台、华为可正常添加）。
- **按机型差异化**：
  - 小米 / 红米：按钮为「授予『桌面快捷方式』权限（米系推荐先点这个）」，点击直达 MIUI 权限页，
    开启后「一键添加」即可弹确认框；
  - 其他机型：按钮为「前往权限 / 应用设置」，跳转系统应用详情页兜底，说明文字同步适配。

## 说明

- 依旧是**零权限、不联网、无广告**，数据只在本机；同一把签名证书，覆盖安装升级数据不丢。
- 已知取舍不变：浅色模式下状态栏时间为白色（实时模糊与状态栏配色的系统级冲突）。
