# TimestampRecorder v4.1.0

## ✨ 主要变化

- **使用教程内置**：教程不再跳 GitHub——「⋮ → 使用教程」和设置页入口现在打开 App 内置教程页，
  离线可读（三步上手 / 小组件两路添加引导 / 卡片四可点区 / 记录管理 / 数据备份）。
  国内连不上 GitHub 也不影响新用户上手。
- **小组件添加引导重排**：统一为两路结构——
  **方式一 · 一键添加**（先授予「创建快捷方式」权限 → 点「一键添加到桌面」）；
  **方式二 · 手动添加**（搜索「你的手机品牌 + 添加安卓原生小组件」→ 按住组件拖到桌面 → 单事件 / 胶囊绑定事件），
  并附小米 HyperOS 4 实测路径作参考。不再维护各品牌逐一说明（差异大、易过时）。
- **关于页新增开发者卡**：GitHub 头像（离线打包，App 依旧零权限）+ 署名
  （独立开发者 · 主贡献者 · 灵感来源），点击跳转 GitHub 主页。

## 📱 兼容性

- 无架构变化，功能与 v4.0.0 一致；`requestPinAppWidget` 行为由桌面（启动器）决定，与 App 无关。
