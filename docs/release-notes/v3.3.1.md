# TimestampRecorder v3.3.1

## 本次更新

- **玻璃材质按深浅色分形态**（经三轮 AOSP 实验确认的最优取舍）：
  - **深色模式**：顶部额头与底部胶囊岛回归**独立窗口 + 系统级实时模糊** —— 老版「高级材质」的质感标杆，滚动零开销、列表从玻璃底下实时穿行。窗口升级为 `TYPE_APPLICATION_PANEL` 子窗口并携带 Activity token，杜绝了旧版探索中的 `BadTokenException`。
  - **浅色模式**：布局内 BlurView 实时模糊（半径加倍补偿、去除双重 overlay 发灰），**状态栏黑化完整保留** —— 浅色模式不创建任何浮窗，状态栏时间/图标恒为深色。
- **修复底部 Tab 栏方形模糊框**：布局内形态的模糊层按背景圆角 outline 裁切（clipToOutline），胶囊岛四角不再溢出方形模糊。

## 为什么分形态（技术说明）

AOSP 三重实验铁证（模拟器 API 36 + `dumpsys` 外观区逐帧验证）：

1. `TYPE_APPLICATION_PANEL` 子窗口（type=1003，携带 Activity token）可以稳定创建（旧版 #8 崩溃仅因缺 token），但**照样夺走状态栏 appearance**；
2. 仅底部岛窗口（frame 完全不碰状态栏）也夺 → **与屏幕位置无关**；
3. 岛窗口 focusable 并自行点亮 appearance → **子窗口的 appearance 请求被 WMS 无视**。

即：**任何浮在主窗口之上的窗口都会把状态栏图标打成白色且无法阻止**；而系统级模糊又必须依赖浮窗（同窗口内容系统合成器不可见）。故深色模式（白图标本就是正常态）启用老材质，浅色模式退回布局内保黑化 —— 两个模式各拿最关键的体验。

## 兼容性 / 降级

- 深色模式系统级模糊需 **Android 12+ 且用户开启「高级材质」**；未满足时浅/深色统一走布局内形态，不会崩溃。
- 用户关闭「高级材质」时不做任何硬模糊（尊重省电选择）。
