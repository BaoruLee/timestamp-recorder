# 时间戳记录 v3.1.4

一次以「**时间线**」和「**沉浸式视觉**」为主的版本：新增时间线视图，并把主界面与各二级页面的
边缘沉浸、底部导航、模糊材质整体重做。

## ✨ 新增

- **时间线视图**：主页底部新增「事件 / 时间线」双 Tab。时间线把全部记录按月份分组，
  左侧一条竖线串联、按事件染色，右侧玻璃卡片显示事件名、具体时间与相对时间（如「3 天前」）；
  点任意一条即可进入对应事件详情页。
- 时间线竖线**贯穿屏幕上下**（从屏幕顶端一直到手势条上方），并在相邻记录之间做
  **颜色渐变过渡**，不再是硬切换色块。

## 🎨 视觉与交互重做

- **底部导航改造成悬浮「胶囊岛」**：整条栏收窄成一颗胶囊浮在底部上方，选中项是岛内嵌的小胶囊；
  「＋」按钮材质与底栏统一，并改为悬在胶囊岛上方。
- **底部玻璃模糊改由系统渲染**：使用系统级窗口背景模糊（HyperOS 的「高级材质」/ AOSP background blur），
  模糊由系统合成器完成，App 端几乎零开销、并且是真·实时（滚动时跟手）。
  **跟随系统开关**：关掉系统的「高级材质」后，底栏自动退回半透明静态胶囊、不再消耗模糊开销。
- **二级页面边缘沉浸全部修好**：设置 / 统计 / 关于 / 小组件绑定 / 事件详情页此前底部内容会被
  在导航栏边界硬截断、露出一条纯背景色；现在内容可以一路「流」到手势条下面，末项依然完整。
- **顶部不再双倍留白**：状态栏区域由工具栏玻璃罩住，不再多出一块空白。
- **底栏圆角处的方形阴影修正**：原来的背景是 layer-list，不提供圆角轮廓，导致系统按矩形投影，
  圆角外露一圈方影；改为单层 shape 后阴影贴合圆角。

## 🐛 修复

- **小组件「一键添加到桌面」**：增加桌面能力预检，并在不支持该接口的桌面上给出**跨品牌**的
  手动添加指引（此前提示只讲小米 HyperOS，在真我等其他机型上驴唇不对马嘴）。
- 设置页「一键添加到桌面」三个按钮不再被挤成两行。

## 🧹 清理

- 删除无引用资源（`bg_bottom_bar`、`bg_liquid_bar`）与已废弃的高开销实时截屏模糊实现（`BlurHelper`）。

## 📥 安装与升级

- 附件 `TimestampRecorder_v3.1.4.apk`，使用与历史版本**同一把证书**签名，
  因此可以**直接覆盖安装** —— **已有事件与记录数据不会丢失，也不需要先卸载**。
- 从任意旧版本升级只需装上这个包即可，其他都不用动。
