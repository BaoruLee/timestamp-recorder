# 时间戳记录 v3.0.1

一次小的界面修正，功能与 v3.0.0 完全一致。

## 🐛 修复

- **设置页「一键添加到桌面」的按钮不再被挤成两行**。之前「全部事件 / 单事件 / 胶囊」三个按钮等宽三等分，
  再加上 Material 按钮默认的左右内边距，留给文字的空间不够，在稍大的系统字体下「全部事件」会折成
  「全部事」+「件」两行。现在收窄了按钮内边距、去掉了多余的外沿留白、锁定单行，三个按钮在任何字号下
  都整齐地排成一行。

## 📥 安装与升级

- 附件 `TimestampRecorder_v3.0.1.apk`，使用与历史版本**同一把证书**签名，
  因此可以**直接覆盖安装** —— **已有事件与记录数据不会丢失，也不需要先卸载**。
- 从 v3.0.0 升级只需装上这个包即可，其他都不用动。
