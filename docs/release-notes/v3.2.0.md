## 新功能

- **主页左右滑动切换 Tab**：在事件 / 时间线两页之间直接横滑，内容跟手、可急停、
  可反向拖回（AndroidX ViewPager2 标准容器）；与列表纵向滚动互不干扰。
- **底部滑块跟手联动**：胶囊岛的选中胶囊逐帧跟随手势移动，与页面滑动完全同步；
  胶囊几何改为自绘（岛宽 ÷2 等分），任何机型密度下都不会错位或铺满。
- **小米「一键添加」权限引导**（仅小米 / 红米机型显示）：设置 → 桌面小组件 →
  「授予桌面快捷方式权限」——HyperOS 需要此权限一键添加才会弹确认框，点按钮直达权限页。

## 改进

- **「＋」按钮跟随事件页运动**：滑向时间线时随页面内容一起滑出屏幕，跟手可急停。
- **两种渲染形态布局一致**：系统高级材质开 / 关（或机型不支持），顶栏高度、
  「⋮」位置、玻璃样式、时间线起点完全相同 —— 不支持模糊的机型上布局也不会乱。
- **跨机型加固**：挖孔屏 / 刘海屏内容延伸声明；状态栏图标配色三条通道全写
  （不同 ROM 认哪条哪条生效）。

## 已知限制

- 浅色模式下状态栏时间为白色：实时模糊与状态栏配色的系统级冲突，取舍保留模糊。
