# TimestampRecorder v3.3.0

## 状态栏配色修复（浅色模式黑化）

- **问题**：浅色模式下，顶部状态栏的时间与图标是白色，压在浅色玻璃顶栏上几乎隐形（看不清）。
- **根因（承接 v3.1.9 的 A/B 实测）**：此前玻璃顶栏 / 底部 Tab 岛用「独立窗口（`TYPE_APPLICATION`）+ 系统级模糊」实现。独立窗口的 `LIGHT_STATUS_BARS` 标志**不被系统记入窗口外观**，状态栏始终按默认白字渲染，运行中任何公开 API 都点不亮。这是 AOSP 通用机制（已在小米 HyperOS、realme ColorOS 上复现），与独立窗口架构**强绑定、无法绕过**——当时的取舍是保留模糊、放弃黑化。
- **修复（架构重构）**：本版换架构彻底绕开这个死结——玻璃顶栏 / 底部 Tab 岛改为在 **Activity 布局内用 BlurView 库**做实时背后模糊，状态栏配色交回 **Activity 主窗口** 控制（主窗口控制就一定生效）。这一改动从架构层面解耦了「实时模糊」与「状态栏黑化」，二者不再互斥。
- **效果**：
  - 浅色模式：状态栏图标 / 时间转为深色，清晰可见；
  - 深色模式：状态栏保持白色文字；
  - 顶部额头、底部 Tab 岛的**实时模糊**保留（BlurView 实现，滚动时内容从玻璃下穿过依旧被糊化）。

## 版本号说明

- 本版新增依赖 **BlurView** 且对玻璃栏做了**架构级重构**（独立窗口 → 布局内 BlurView），按语义化版本规则（新依赖 / 架构重构 → `x.y.0`）升为 **3.3.0**（一度误拟 3.2.2，已纠正为 minor）。
- 双 Tab（事件 / 时间线）、滑块跟手联动、＋号随事件页平移、桌面小组件权限按钮等交互与功能**全部保留**，无功能回退。

## 验证

- `dumpsys window` 确认 `mLastAppearance=LIGHT_STATUS_BARS` 已置位（状态栏外观交回主窗口控制生效）；
- 模拟器浅色模式截图像素扫描：状态栏区域检出深色像素（旧架构下应≈0），黑化修复客观成立；
- UI 层级 147 个节点**零越界**、无组件错位、进程无崩溃；
- 模糊观感（硬件加速下的实时模糊细腻度）仍由各机型真机确认。

## 其他

- 覆盖安装不会丢失已有事件与记录数据。
- 实时模糊为应用层效果，真机（硬件加速）表现最佳；低版本降级路径未实机验证。
